# Read to Output｜英文原版阅读与输出系统

这里收录两套从同一学习实践中长出来的本地工具：一套是可直接交给 Claude Code / Codex 使用的学习 Skill；另一套是把流程做成更轻量、更可控的本地程序 RTO。

它们都围绕同一件事：把英文原版阅读从“读完就过去”，变成能讲清、能核对、能留下进度与输出痕迹的过程。

## 1. Feynman Skill

适合已经在 Claude Code 或 Codex 中使用 Skill 的人。它把分段阅读、开卷费曼讲述、原文核对、选择性知识复习和英语回译串成学习闭环。

- [查看 Skill 说明与安装方式](feynman/README.md)
- [查看 Skill 文件](feynman/SKILL.md)

## 2. RTO（Read-to-Output）本地程序

RTO 是上述工作流的程序化版本，目前是 beta。它运行在本地，主要配合 Pi 与 Obsidian：

- 用菜单选择今天读哪本书、如何推进；
- 把阅读、费曼讲述、原文范围核对、笔记存档拆成明确状态；
- 需要时再进入回译与复习，不让 AI 每次都重读整份学习进度；
- 学习数据保留在本地 Obsidian，不上传到服务器。

- [进入 RTO 项目与安装说明](rto/README.md)
- [阅读产品案例：我用 AI 做出了产品，却把自己的需求当成了市场](rto/docs/rto-product-case.md)
- [下载 Windows / macOS beta.2 压缩包](rto/read-to-output-pi.zip)

> RTO 仍在内测期。它解决的是“本地学习流程怎样更稳定、更省上下文”的问题，不把它包装成已经验证了需求的成熟产品。产品案例保留了这次尝试的过程、判断失误和得到的结论。

## 适合的材料

两套工具都更适合有连续语境、需要理解概念、论证或因果关系的英文材料，例如历史、社会科学、思想与通识著作、叙事性非虚构、连续论证文章和教材章节。

它们不适合替代 API 文档、参数表、代码参考或以单点检索为主的资料阅读；这些更适合检索、示例验证或任务式练习。
