# Read-to-Output（RTO）

> 一个把“读英文原版书 → 讲清楚 → 对照原文核对 → 选择性回译”做成固定流程的本地学习工具。

RTO 是我为自己做的英文原版书学习系统。它运行在本地终端，把学习进度、阅读范围、费曼笔记和可选的回译训练写回你的 Obsidian 库。它不试图替你阅读或替你总结，而是把“读完以后到底有没有讲明白”这件事变成可继续、可核对、可存档的流程。

这是一个仍在内测的个人工具，适合愿意使用 Obsidian、英文电子书和本地 API 的学习者。它目前不适合追求手机随开随用、碎片化刷题，或希望一键获得可视化学习反馈的人。

## 它能做什么

- 按章节或时间规划英文原版书阅读，并精确记录本次实际读到的范围；
- 读完后进入费曼讲述：你先用自己的话解释，AI 只在已读原文范围内追问；
- 按“准确理解 / 合理推断 / 需要修正 / 原文补充”核对讲述，并把结果存入 Obsidian；
- 提供可关闭的回译与复习队列；
- 本地保存状态和备份，写入前会检查文件是否被外部改动，失败时回滚。

## 为什么做它，以及为什么它没有成为一个好产品

这个项目起点不是“做一个 AI 学习产品”，而是我自己读英文原版书时反复遇到的问题：读完会忘、理解停在模糊处、知道费曼法有效却很难稳定执行。RTO 把我自己的流程固定了下来，也让我第一次认真面对一个事实：**一个对创作者很有用的产品，并不自动等于一个适合大多数人的产品。**

完整复盘见：[《我用 AI 做出了产品，却把自己的需求当成了市场》](docs/rto-product-case.md)。

## 快速开始

目前请下载发布包，按其中的安装提示词完成本地配置。Windows 用户双击 `start-read-to-output.cmd`；macOS 兼容性内测用户运行 `bash start-read-to-output.command`。

项目和安装说明仍在持续调整。若你参与内测，请优先反馈：你在哪一步停下、你原本想完成什么、以及是否愿意第二次打开它，而不只是报一个报错。

## 开发与流程细节

当前版本：v0.10.6-beta.2

这个原型把英文原版阅读流程拆成三个程序控制的阶段：阅读、费曼讲述、原文核对。正式模式现在可以安全写入 Obsidian；它仍然不会修改正式 Skill。

## 运行

在任意终端输入 `rto`，或者双击 `start-read-to-output.cmd`。专用启动器会关闭全局 Skills、扩展、提示模板、上下文文件和模型工具，只加载本项目的学习扩展。首次启动会引导连接 Obsidian、配置模型和导入图书；之后会打开主菜单。已有学习场时，第一项会准确显示“继续阅读 / 继续费曼 / 继续核对”；已有分段计划的书会直接续读下一段，不重复选择规划模式。

正式模式会在开始阅读时标记当前范围；核对完成后保存费曼笔记、勾选或续接当前分段、追加表达力记录、更新英语输出节奏，并标记下一段。每次正式存档前都会把原始 `学习进度.md`、章节文件和结构化状态复制到 `.read-to-output/backups/`。如果文件在本轮中被外部修改，系统会拒绝写入；多文件写入失败时会自动回滚。

开发测试使用 `rto-test`。它只操作项目内的 `sandbox-vault`，可以真实测试起终点标记、费曼笔记存档和下一段推进，但绝不会写入真实 Obsidian。测试乱了可在另一个终端输入 `rto-test-reset` 一键恢复。

为了避免用真实学习时间测试，在 `rto-test` 中直接输入“演示一下”：阅读阶段会自动提交预制讲述，学生追问后再次输入会自动提交预制回答。讲述完成后说“总结吧”即可测试核对、存档和推进。旧命令 `/learn demo` 仍然可用。

第六阶段加入了独立的沙盒回译闭环。完成并核对一个分段后，输入“回译”即可从该段实际已读原文中生成一道题；英文候选必须逐字存在于已核对范围，程序审核通过后才显示中文。提交英文后会显示分层批改和原文；首次答案完全通过时直接存档，不再要求原样重写，有必须修改的问题时才完成一句针对性重写。第七阶段加入复习队列：每题必做第 2 次；只要第 1 次或第 2 次没有通过，就在跳过一个输出位后做第 3 次。复习中文与参考英文在首次批改后锁定，不会随复习漂移。第八阶段将同一流程接入正式 `rto`：回译笔记写入真实 Obsidian，复习队列保存在本地运行目录，每次正式提交都创建写入前备份并在多文件提交失败时回滚。`rto-test` 仍只操作沙盒。

第九阶段加入选择性知识复习队列。只有学习者主动说“我想记住：……”或“这个我想记住”，知识点才进入队列，3 天后首次提醒；每段存档后不再强制追问。启动时若有到期项，会问“要花约 2 分钟回忆吗？”，用户拒绝后不再追问、不阻止阅读。复习时凭记忆讲述，短模型判断是否准确：通过按 3→7→14→30 天延长间隔，30 天通过即毕业；未通过退回上一级间隔；模型不可用或格式异常时本次不计错、不改变间隔；随时可回复“停止追踪”不再提醒该项。队列保存在 `.read-to-output/knowledge-queue.json`（沙盒为 `.read-to-output-sandbox/`），正式模式同样受 `writeMode` 和快照新鲜度保护。

第十阶段加入新章节自动分段计划。选中的书没有分段计划时，选择“按章节分段”或“按时间规划”都会先自动规划：程序读取章节文件（只读、不调模型、不向用户泄露内容），按空行和小节边界拆块，以每段约 650 词为目标生成足够数量的分段，不再为了限制总段数而把超长章节压成大段；每段选唯一的起止锚点行（跳过图片、FIGURE、页脚等噪音行，避开含引号的行以保证进度文件格式可解析），并按输出节奏把每第三段标记为混合场。规划结果写入 `学习进度.md` 的 `### 分段计划` 区块（替换旧计划）和 `state.json` 的 `nextSegment`，正式模式带写入前备份与失败回滚。时间模式在规划基础上按分钟数裁剪阅读范围，不改变分段结构。

第十一阶段接入三档频率调度。混合场阅读范围在分段模式下自动缩短到约 65%（剩余内容留给下一场）；混合场完成阅读后，启动时会提示“上一场是混合场，回译还差一个输出位”。每次完成回译（新题或复习）后，程序按原 skill 的自适应数量规则更新节奏：普通阅读场计数归零、下次场次改回普通阅读场，新题连续两次无“必须修改”且约 10 分钟内完成时把新回译参考量从 25–40 词提到 40–55 词；单次超过 15 分钟或出现 3 个以上独立的“必须修改”时降到 20–30 词。普通场用户主动回译不改变阅读计数，只更新参考量档位。正式模式更新节奏时把 `学习进度.md` 和 `state.json` 一并纳入备份/回滚事务，并同步刷新快照。

第十二阶段补齐产品化能力。读完本章最后一段后自动推进到下一章（扫描章节目录、更新状态与进度文件、清除旧分段计划区块），并在推进后自动基于本章全部费曼笔记生成“章节骨架”串联笔记（只使用用户自己讲过的内容，不引入外部知识）。表达力追踪改为自动计时：阅读开始记录、跨会话恢复重置计时起点、读完结算，时长与速度（词/分）自动写入表格并用于时间模式的规划估算。回译完成后自动检测拼写错误（编辑距离 ≤2、排除专名），同一词第二次拼错时写入 `回译错题单词本.md`。旧手动规划中的“锚点截断在行中间”问题会在存档时自动修复并同步词数。新增 `/learn add-book`：输入 EPUB（内置最小 zip 解析器）或 TXT 文件路径即可自动拆章、写入 Obsidian 目录、注册到配置，粉丝无需手动整理文件。快捷键：F2 推进流程（阅读完/总结），F3 撤回上一步，Ctrl+Shift+Enter 为推进备选。

第十三阶段做新人体验与回译模式。新增三档回译模式（`/learn mode`）：off 纯阅读、light 轻量（两次阅读一次回忆，默认）、heavy 重度（每次阅读后必做回译，未完成会被流程拦截）。新增 `/learn help` 使用总览、`/learn api` 配置模型 key、首次引导时解释 Obsidian 作用并提供 API 官网链接、首次费曼示例引导、宽容自然语言（看完了/我讲完了）、用户可见错误信息去术语化（17 条映射）、正式模式“演示一下”全流程演示（不写入任何笔记）。修复新人链路：导入短章节书降级为单段、导入后刷新学习进度快照、自动创建图书区块。

## 一次学习怎么走

正常学习不需要记命令。输入“继续”会直接续读上次那本书已经规划好的下一段；输入“今天学什么”可以改选其他书。选中的书若已有分段计划，会直接进入下一段；只有尚未建立计划时，才需要选择“按章节分段”或“按时间规划”。选择时间模式时，再输入今天的总学习分钟数；系统会先为费曼和核对预留时间，然后安排阅读范围。

读完后输入：

```text
读完了
```

系统随即进入费曼阶段。直接用中文讲学到了什么；讲清楚后说“总结吧”“没有了”或“没有补充了”，程序会确定性地切换到原文核对，不让模型自行决定是否收尾。完整流程是：

```text
启动 → 选择书 → 选择分段/时间规划 → 阅读 → 读完了 → 费曼讲述 → 总结吧
```

程序在本地读取当前分段，并把精确原文缓存到 `.read-to-output/active-session.json`。它不会把整章送给模型，也不会在阅读阶段调用模型。若关闭后重开，程序会恢复未完成的阶段、第一次完整讲述以及后续逐轮“学生问题—用户回答”；核对阶段只按这些真实记录总结，不从原文反推用户讲过什么。

如果没有读完整段，用实际读到的末句片段缩短边界：

```text
/learn stop 你实际读到的末句片段
```

只有从费曼讲述开始，模型才会收到“费曼学生规则 + 实际已读原文”。原文用来限制问题边界，不是用来考遗漏或记忆。

讲清楚后直接说：

```text
总结吧
```

也可以用调试命令 `/learn verify`。这时系统才切换到原文核对，区分准确理解、合理推断、需要修正和原文补充。

若发现核对结果有问题，可直接输入“重新核对”。旧版场次没有完整保存逐轮问答时，系统会明确标注记录不完整，但仍会恢复第一次完整讲述，禁止写成“没有被追问”。

第五阶段启用前已经完成核对、但尚未正式存档的旧会话，会显示“待写入真实 Obsidian”。由于旧版没有单独保存最终总结，需要输入“重新核对”，系统才会重新生成总结并执行一次正式存档；不会跳过旧会话直接覆盖进度。

第三阶段把原 Skill 的费曼行为拆成按需提示词：首轮先核验讲述范围，通过后才加载学生追问规则；核对阶段只加载核对与完整总结格式。模型问题、模型转述和用户的简短确认不会再自动算作用户主动掌握。输入“总结”或“总结吧”都能切换到核对阶段。

第四阶段增加了独立的提问输出审核。学生模型流式生成时只显示“正在审核问题…”，候选问题不会提前露出；生成完成后，再由一个不带工具、只看“实际已读原文 + 用户已经讲出的内容 + 候选问题”的短模型调用审核。只有答案确实存在于当前原文中的问题才会显示；如果问题只是和原文主题相关、但追问了本段没有解释的原因或机制，系统会拦截并结束该问题。审核格式异常或调用失败时也按不通过处理。代价是每次候选学生回应会多一次很短的模型调用。

第五阶段增加了事务式正式存档。整段阅读完成后推进下一段；时间模式只读完当前分段的一部分时不会误勾整段，而是保留当前段并把下次起点推进到剩余内容。正式写入必须由 `.read-to-output/config.json` 中显式的 `writeMode: "real"` 开启。

第六阶段把回译做成独立状态机，没有扩充或改写已经稳定的阅读—费曼—核对状态机。沙盒中的完整流程是：

```text
回译 → 原文内选题审核 → 英文作答 → 分层批改 → 一句重写 → 核对并存档
```

第七阶段在这个独立状态机上增加程序化复习：再次输入“回译”时，系统优先取到期旧题；没有到期旧题才生成新题。原题训练重点与本次纠错重点分别记录，避免把“为什么选题”和“这次实际错在哪里”混为一谈。

每次回译或复习完成后，系统会主动询问是继续当前阅读分段还是换一本书；用户只需回复“继续阅读”或“换一本”，不需要反过来提醒 Agent 询问“今天学什么”。

第八阶段启用正式回译写入。正式模式必须同时满足：最近分段已经核对并正式存档、`writeMode` 明确为 `real`、学习状态快照没有过期。程序会把最近完成并核对的分段另存为 `.read-to-output/last-verified-session.json`，所以即使已经开始阅读下一段，回译仍会使用上一个已完成分段，不会被当前“阅读中”的状态覆盖。回译不会修改章节标记，也不会自行推进阅读进度；它只写入 `回译/` 笔记和 `.read-to-output/backtranslation-queue.json`。普通阅读结束后仍不自动催促，只有用户明确输入“回译”才启动；如果没有可用的已核对分段，失败也不会占用回译输出位。新题选题若因模型漏掉结构化标记而失败，系统会在后台自动重试两次，不再立即把重复操作转嫁给用户。

普通阅读启动不会加载回译提示词；只有用户明确输入“回译”后，才读取最近已核对分段和当前回译状态。

## 当前边界

- 启动时只读小型结构化状态，不读 `学习进度.md` 正文或章节正文；
- `/learn start` 只在本地提取当前分段，不调用模型；
- 费曼和核对只注入实际已读范围，提前停止后的文字不会进入模型；
- 每个候选费曼问题在显示前都经过独立边界审核，审核失败时原问题不会显示；
- 正式核对完成后更新费曼笔记、学习进度、表达力追踪、节奏计数和 Obsidian 起终点标记；
- 新章节自动分段已接入：无计划的书选择“按章节分段”或“按时间规划”时自动规划并写入进度文件和状态；锚点必须单行、唯一、不含引号，个别异常章节（如段内所有行都含引号）会报错并等待手动规划；
- 本章最后一段存档后自动推进到下一章并生成章节骨架串联笔记；自动计时写入表达力追踪；回译错题本自动沉淀稳定拼写错误；`/learn add-book` 支持 EPUB/TXT 导入（EPUB 内置 zip 解析器，无需第三方依赖）；
- 新回译和第二/第三次复习已经可以在 `rto-test` 与正式 `rto` 中运行；正式写入有独立备份和回滚。三档频率调度已接入：混合场自动缩短阅读范围、启动提示混合场待输出、回译完成后计数归零并按自适应数量规则调整参考量档位（25–40 → 40–55 → 20–30 词）。回译仍由用户明确触发，不会自动开始；
- 选择性知识复习队列已接入：学习中随时可说“我想记住：……”入队，系统不在每段结束后强制追问；启动时提示到期项，复习通过按 3→7→14→30 天延长、未通过退回上一级，可随时停止追踪；复习判断不可用或格式异常时不计错，也不改变间隔。
