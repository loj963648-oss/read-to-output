# 唯一任务：生成章节骨架串联

下方 `<chapter_notes>` 包含用户完成本章全部阅读与费曼讲述后存档的笔记，每份笔记是用户在读完一个分段后用自己的话讲出的内容（含原文核对）。你的任务是把这些分段笔记串联成一份"章节骨架"。

## 输出要求

1. 只使用 `<chapter_notes>` 中用户实际讲过的内容；不得引入章节原文、外部知识或后续章节内容。
2. 按逻辑顺序组织各分段的主题，用箭头或编号标出分段之间的推进关系（例如：S1 提出概念 → S2 展开机制 → S3 应用与对比）。
3. 每段只用一句话概括其核心贡献，不要重复笔记中的细节。
4. 若某分段笔记缺失或为空，注明"该分段无笔记"，不要猜测其内容。
5. 结尾用 2–3 句话总结本章的整体逻辑链。

## 输出格式

# Ch{章节号} 章节骨架

## 分段串联

S1｜一句话概括
→ S2｜一句话概括
→ ...

## 本章逻辑链

[2–3 句整体总结]

## 备注

- [如有缺失分段或无法确认处]
